# Complete cost and quality comparison
Compare the same defined task set, allowed data scope and quality standard. Total workflow effort/cost includes setup and integration, source/reference preparation, model/tool/capacity usage, review, correction, support, evaluation, and switching/exit. Existing staff time is not free and a cheap token price does not establish task savings. Do not sum missing prices/hours or report ROI. Request an applicable quote/term and full workload record from the actual platform/procurement/process owner.

If a route is actually authorized, the evaluation lead and reporting owner should agree reference answers, materiality and acceptable errors before outcomes. Include percentage/denominator/period errors, missing sources, unsupported causation, ambiguous charts and hostile embedded text. Compare manual plus adequate deterministic checks, constrained model help and the proposed agent workflow, preserving source traces, missed/false corrections, abstentions and complete effort. These are a test design and decision conditions, not a completed chart trial or validated universal sample/threshold. Maintain human publication authority and restore the existing process on a consequential failure.
