# Test and revision record

Eight final profiles keep technology, intended application, organization type, posture and risk constant. The principal contrast changes only capabilities_constraints and supplies materially different organizational conditions. General and application findings are deliberately held identical; this is a controlled reasoning comparison, not independently replicated model reliability.

Controlled v0.1 diagnostic: two deliberately underspecified weak-rule responses are preserved with their rules/metadata and exact prompt packets. They infer readiness from analyst experience/BI assets, fill unknowns optimistically, give the same generic pilot advice and confuse organizational gaps with technology immaturity. These are current same-assistant controlled negative examples, not an invented historical incident or an independently sampled model failure.

Version 1.0 corrects that rule by separating fit from readiness, covering all eight domains, distinguishing supported/gap/unknown, forbidding score compensation, naming P0/P1/P2 dependencies and proposed owners, and requesting missing capacity/ownership evidence. On the same primary/contrast inputs, the baseline is not ready and the fully specified fictional R1 profile supports only conditional organizational readiness. L1 never becomes routine-use approval. Sponsor-only enthusiasm and the hype memo cannot waive the baseline blocker.

The capacity-unknown profile asks for demand, review time, protected hours and contingency instead of inventing a ratio. The shortfall fixture has 24 planned review hours versus 12 protected, and a separately withdrawn owner reverses readiness even with a sponsor. These tests check specific behavior rather than count generic checklist prose as success.

An actual packaging issue occurred while reconstructing the weak prompts: the canonical builder expects specialist_instructions.md, but the archived file initially had a version-suffixed name. The archive now uses its own versioned metadata/folder with the canonical filename. Both prompt packets rebuild exactly; no frozen tool was modified.

The assistant reasoned through and authored the qualitative responses. Scripts serialize them, rebuild prompts, check contracts, integrity, case isolation and arithmetic. There was no external inference API, isolated model repeat, independent evaluator or real organization/technology trial. Known limitations and failures remain visible rather than being rewritten as first-try success.
