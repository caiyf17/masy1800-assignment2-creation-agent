# Test and revision record

## Saved diagnostic overclaim
The intentionally permissive 0.1 diagnostic baseline and its hype response are preserved under agents/promethean_classification_agent/revisions/v0_1. It accepts generation-only speed and market excitement as enough for a high-significance label, then lets that label recommend production. This is an assistant-authored negative design control, not an independently observed model trial or a result attributed to the student. Keeping this distinction is essential: a deliberately constructed failure can illustrate a rule defect but cannot measure how often a model would fail.

## Diagnosis and change
The defect is a chain of unsupported transfers: component/task claim to system performance, interest to civilizational reach, and broad significance to local adoption. Version 1.0 adds two gates, explicit denominators, a C1-C6 evidence matrix, date/scope checks, withheld verdicts and bounded expert routing. The same hype input is retained byte-for-byte for the corrected example; it is not simplified to manufacture success.
