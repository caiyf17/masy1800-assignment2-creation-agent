# Initial rule baseline for controlled comparison
Use the general technology evidence and organizational posture to suggest a small pilot before broader adoption. Keep a human reviewer and learn whether the application is useful. Explain uncertainty, but do not require a distinct PoC/pilot boundary, full-cost comparator, hard data gate or explicit stop/promotion conditions.
This intentionally under-specified baseline is preserved to expose a design weakness. It is not a previously deployed agent or an independent model run.
