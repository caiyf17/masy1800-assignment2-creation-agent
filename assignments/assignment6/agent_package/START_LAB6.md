# Lab6 entry point

Use agents/adoption_agent, not the original toy or _template folders. Read the Agent Record one folder above this package, then records/decision_policy.md and records/team_handoff.md. Eight current prompt/JSON examples and preserved weaknesses make the rule changes inspectable. These are same-assistant qualitative examples, not independent model runs or company pilot results.

Run python verification/recheck.py using standard-library Python. To create a fresh prompt use the unchanged tools/build_prompt.py. Open the saved packet in ChatGPT, save the returned JSON separately, and use tools/validate_response.py. No API key or actual deployment integration is required. The original PACKAGE_SHA256.txt covers teacher files; the outer SHA256SUMS.txt covers the complete student delivery.
